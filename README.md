# POCs

Este es un ejercicio de aprendizaje de inteligencia artificial probabilistica, inferencia causal y exploración de ideas personales.

Estructura del repositorio:
```
pocs/
├── .venv/                # Entorno virtual (si configuras poetry para crearlo in-project)
├── data/                 # Raw, processed y final data
├── img/                  # Imagenes, archivos fuentes Excalidraw
├── notebooks/            # Archivos .ipynb
├── src/                  # Código fuente (clases, funciones, lógica de ML)
│   ├── __init__.py
├── pyproject.toml        # Configuración de Poetry y dependencias
├── poetry.lock           # Versiones exactas bloqueadas
└── README.md
```
